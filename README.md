# BP26 London Generator

A cyberpunk-utopic Solana Breakpoint 2026 (London, 15–17 Nov 2026) profile picture generator. Upload a photo, enter your handle, and get a composited pfp — circle crop, glitch-text branding, London skyline (Big Ben, the Shard, the Gherkin), and Solana brand colors — ready to save and set as your X profile photo.

## Status

This is a working front-end demo: all the cropping, skyline, glow, and glitch-text compositing happens live in the browser with Canvas — no backend, no build step, open `index.html` directly.

**What it does today:** circle crop, cover-fit photo placement, a moody duotone/chromatic-aberration filter on the uploaded photo, the London skyline silhouette, the glitch-text headline treatment (Anton + Rajdhani, RGB channel split), and the Solana logomark.

**What it doesn't do yet:** the full AI-generated distortion (datamosh/pixel-dissolve breakup of the skyline, deeper stylistic repaint) that we prototyped in Gemini. That needs a real image-generation API call — see "Next steps" below.

## Running it

This now has a real backend call for the AI image generation, so it needs Vercel (or `vercel dev` locally) rather than a plain static server — a bare `index.html` double-click won't hit `/api/generate`.

1. `npm i -g vercel` (if you don't have it)
2. In the project folder: `vercel dev`
3. Get a Gemini API key at https://aistudio.google.com/apikey
4. Copy `.env.example` to `.env.local` and paste your key in
5. Open the local URL it prints, upload a photo, hit Generate

### Deploying

1. Push this repo to GitHub, import it into Vercel (framework preset: **Other**, no build command needed)
2. In Vercel → Project Settings → Environment Variables, add `GEMINI_API_KEY` with your key
3. Redeploy — the live site now actually generates each pfp through Gemini, not just a canvas filter

## Design system

**Updated 2026-10-13: the real recipe now matches Solana's own Breakpoint 2026 marketing** (confirmed against official speaker cards and the homepage hero), which turned out to be simpler and more disciplined than our earlier multicolor glitch-text experiments:

- **Duotone, not multicolor.** One accent color (Solana Purple `#9945FF`, or Green `#14F195` for a variant) over black and white. Never a magenta-purple-green gradient blend.
- **The glitch lives in the photo, not the text.** A vertical pixel-sort/datamosh band, confined to roughly the right third of the frame — sharp rectangular bars of varying height. The rest of the image, face included, stays clean.
- **Headline/handle text stays completely clean.** No RGB split, no chromatic aberration on the letters — that was our earlier invented style, not the brand's. Plain, confident, bold sans-serif.
- **Black background**, no skyline/scene behind the subject in the official assets.
- **This is now a real AI generation pass** (`api/generate.js`, calling Gemini), not a canvas filter — see "Running it" above. The exact locked prompt lives in that file; it's the one thing that must stay identical across every request so every user's output matches the same template.
- The BP26 logomark (three stacked parallelograms) stays small, static, undistorted — composited in code, never regenerated by the AI, so it's always pixel-correct.

The old Rajdhani/Anton glitch-text + skyline design-system artifact predates this correction — treat this README as the current source of truth until that artifact is updated to match.
